# Contributing

Thanks for your interest. **We aren't accepting outside pull requests yet.**

Extremely Autonomous Agents is licensed under the AGPL-3.0 and is also offered
as a paid hosted service. Before we can merge code from outside contributors,
we need a Contributor License Agreement (CLA) in place, so the project can keep
offering it under both. Until then:

- **Issues and bug reports are welcome.**
- Pull requests from outside the core team will be closed without review.

Once the CLA is ready, this file will say how to sign it and contribute.
